## 按目前分組報價

KDAN 提供靈活的模型選擇和清晰的分組費率。下方價格表讀取目前所選分組的報價；優惠、倍率和單獨定價以該分組目前設定為準，不承諾固定折扣。

公開頁面選中的分組不一定是你的 API Key 綁定的分組。呼叫前請在 [API 金鑰](/keys) 確認分組，並在 [模型廣場](/model-plaza) 檢視對應模型的計費方式與價格。最終費用以實際請求適用的規則和用量記錄為準。

## 讀懂價格表

- **分組價格**：所選分組套用倍率或逐模型定價後的報價；已展示的實付單價不應再乘一次折扣。
- **官方參考價**：用於對比的上游價格資料，不是額外收取的一筆費用，也不代表你的 Key 最終單價。
- **按 Token 計費**：按輸入、輸出、快取讀取和適用的快取寫入等專案分別計算。單位通常為每百萬 Token。
- **按張計費**：按模型、尺寸或其他已設定檔位的每張單價計算，不套用 Token 公式。
- **價格缺失**：不代表免費；先確認設定和可用性，再發起請求。

```text
Token 項費用 = 該項計費 Token 數 ÷ 1,000,000 × 該項有效單價
按張費用 = 計費圖片數量 × 對應檔位的每張有效單價
```

## 階梯與額外費用

長上下文、快取時長、服務等級和工具呼叫可能有不同價格。僅在對應模型與分組規則明確支援時適用，不把某個模型的閾值或倍率推廣到所有模型。同一計費專案不要重複計算；請求重試可能產生新的用量。

官方參考：[OpenAI 價格](https://openai.com/api/pricing/)、[Anthropic 價格](https://platform.claude.com/docs/en/about-claude/pricing)。本站報價與官方直連價格可能不同。
