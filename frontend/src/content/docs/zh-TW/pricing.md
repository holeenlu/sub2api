## 依目前群組報價

Tokensavy 提供靈活的模型選擇與清楚的群組費率。下方價格表讀取目前所選群組的報價；優惠、倍率及個別定價以該群組目前設定為準，不承諾固定折扣。

公開頁面所選的群組不一定是你的 API Key 所屬群組。呼叫前請在 [API 金鑰](/keys) 確認群組，並在 [模型廣場](/model-plaza) 查看對應模型的計費方式與價格。最終費用以實際請求適用的規則與用量記錄為準。

## 看懂價格表

- **群組價格**：所選群組套用倍率或逐模型定價後的報價；已顯示的實付單價不應再乘一次折扣。
- **官方參考價**：用於比較的上游價格資料，不是額外收取的費用，也不代表你的 Key 最終單價。
- **依 Token 計費**：分別計算輸入、輸出、快取讀取及適用的快取寫入等項目。單位通常為每百萬 Token。
- **依張數計費**：依模型、尺寸或其他已設定級距的每張單價計算，不套用 Token 公式。
- **價格缺漏**：不代表免費；請先確認設定與可用性，再發出請求。

```text
Token 項目費用 = 該項計費 Token 數 ÷ 1,000,000 × 該項有效單價
依張數費用 = 計費圖片數量 × 對應級距的每張有效單價
```

## 級距與額外費用

長上下文、快取時長、服務等級與工具呼叫可能有不同價格。僅在對應模型與群組規則明確支援時適用，不將某個模型的門檻或倍率套用至所有模型。同一計費項目不要重複計算；請求重試可能產生新的用量。

官方參考：[OpenAI 價格](https://openai.com/api/pricing/)、[Anthropic 價格](https://platform.claude.com/docs/en/about-claude/pricing)。本站報價可能與官方直接呼叫價格不同。
