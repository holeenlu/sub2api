## 按当前分组报价

KDAN 提供灵活的模型选择和清晰的分组费率。下方价格表读取当前所选分组的报价；优惠、倍率和单独定价以该分组当前配置为准，不承诺固定折扣。

公开页面选中的分组不一定是你的 API Key 绑定的分组。调用前请在 [API 密钥](/keys) 确认分组，并在 [模型广场](/model-plaza) 查看对应模型的计费方式与价格。最终费用以实际请求适用的规则和用量记录为准。

## 读懂价格表

- **分组价格**：所选分组应用倍率或逐模型定价后的报价；已展示的实付单价不应再乘一次折扣。
- **官方参考价**：用于对比的上游价格资料，不是额外收取的一笔费用，也不代表你的 Key 最终单价。
- **按 Token 计费**：按输入、输出、缓存读取和适用的缓存写入等项目分别计算。单位通常为每百万 Token。
- **按张计费**：按模型、尺寸或其他已配置档位的每张单价计算，不套用 Token 公式。
- **价格缺失**：不代表免费；先确认配置和可用性，再发起请求。

```text
Token 项费用 = 该项计费 Token 数 ÷ 1,000,000 × 该项有效单价
按张费用 = 计费图片数量 × 对应档位的每张有效单价
```

## 阶梯与额外费用

长上下文、缓存时长、服务等级和工具调用可能有不同价格。仅在对应模型与分组规则明确支持时适用，不把某个模型的阈值或倍率推广到所有模型。同一计费项目不要重复计算；请求重试可能产生新的用量。

官方参考：[OpenAI 价格](https://openai.com/api/pricing/)、[Anthropic 价格](https://platform.claude.com/docs/en/about-claude/pricing)。本站报价与官方直连价格可能不同。
