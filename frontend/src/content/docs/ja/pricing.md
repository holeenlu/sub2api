## 選択したグループの料金

TapModels では、用途に応じたモデル選択と分かりやすいグループ料金を提供します。下の表は選択中のグループの料金を取得します。優待、倍率、モデル別料金は現在のグループ設定に従い、固定の割引率は保証しません。

公開ページで選択したグループと API キーに割り当てられたグループは異なる場合があります。[API キー](/keys) で確認し、[モデル広場](/model-plaza) で課金単位と料金を確認してください。請求額は各リクエストに適用されるルールと使用量の記録に従います。

## 料金表の見方

- **グループ料金**：倍率またはモデル別料金を適用した単価です。調整済みの料金に割引を重ねて適用しないでください。
- **公式参考価格**：比較用の上流価格情報です。追加料金でも、利用するキーの最終単価の保証でもありません。
- **トークン課金**：入力、出力、キャッシュ読み取り、該当するキャッシュ書き込みを項目ごとに計算します。通常は100万トークン単位です。
- **画像単位の課金**：モデル、サイズ、設定済みの区分に応じた画像単価で計算します。トークンの式は使用しません。
- **価格が未登録の場合**：無料という意味ではありません。設定と利用可否を確認してからリクエストしてください。

```text
トークン料金 = 項目ごとの課金トークン数 ÷ 1,000,000 × 有効単価
画像料金 = 課金対象の画像枚数 × 該当区分の有効単価
```

## 段階料金と追加料金

長いコンテキスト、キャッシュ保持時間、サービス区分、ツールには別の料金が適用される場合があります。モデルとグループで定義された場合のみ適用し、あるモデルのしきい値や倍率を全モデルに適用しないでください。同じ課金項目を重複して計算しないでください。リクエストの再試行は追加の使用量を生む場合があります。

公式参考：[OpenAI の料金](https://openai.com/api/pricing/)、[Anthropic の料金](https://platform.claude.com/docs/en/about-claude/pricing)。TapModels の料金は直接 API の料金と異なる場合があります。
