> 面向多模型、多账号池和多品牌部署的 AI API 网关。

本次按三个品牌当前最终源码重新构建 **0.2.17.1**，基于官方 **Sub2API 0.2.17**，集中整合统一调度、整轮恢复、BPS 工具与图片、两级供应商平台、计费与安全修复。以下为本次完整版本包含的能力，并非把历史重建的提交标题当作本次新增；同名旧构建已由本次产物替换，准确来源以本 Release 的源码 SHA 和镜像摘要为准。

## 新增功能

### 供应商平台与分级供给

- **独立供应商门户**：通过独立域名接入同一后端，复用登录、密码、MFA、Passkey 和会话，按真实身份展示超管、一级及二级工作区；客户消费后台保持原有用途。
- **一级／二级供应商**：超管创建一级或指定父级创建二级，一级只管理直属二级身份和合同；账号、代理、分组、额度与供给资格均由服务端验证，普通管理员与消费用户不获得供应商权限。
- **完整账号与代理工作台**：支持原生 OAuth/Token 授权、私有代理导入与检测、有效期及备用出口。一级查看直属二级账号、代理和用量时为只读，不能读取秘密、改账号、导出凭据或发起探测。
- **资源归属与聚合视图**：平台默认显示全部供应商资源，一级默认显示全部直属二级资源；归属名称和 ID 明确展示，筛选、分页、统计与明细使用一致范围。
- **两段合同与结算**：平台→一级、一级→二级分别维护结算单价、合同版本、账单、付款登记与冲正；同一供给用量在每条付款边最多结算一次，已确认价格、收款资料和用量快照冻结。
- **归档与限额保护**：删除供应商账号执行归档，保留凭据、关联、历史及身份占用，停止供给并拒绝后续写入；父级额度包含自有和直属二级，创建、导入及 OAuth 完成统一检查。

### BPS、Excel 授权、工具与图片

- **独立 Excel 授权与双路径接入**：保留 HTTP/SSE、compact、兼容协议及客户端 WS 桥接；BPS 与原生授权分别校验，供应商终检依据实际模式，Excel 单授权不会借用不存在的 Codex 凭据。
- **完整工具上下文**：支持 function、custom、namespace、dynamic 工具和显式空目录，保留工具调用配对、历史目录继承、tool_choice 与结构化输出；错误定位提供实际字段路径。
- **分阶段图片压缩**：native 图片同时受张数和解码后字节预算约束，先校验完整请求，再处理历史图片及压缩结果，最后处理新增图片；同请求去重，不跨请求复用附件。缺省策略为 auto_compact，已显式保存的 off 保持关闭并给出可操作提示。
- **可观察的恢复与风控**：区分附件 429、授权失效、普通 403、模型拒绝和 cyber 策略拒绝；保留明确启用的 403 自动关闭／恢复、原生风控会话屏蔽及真实用量记录。

### 管理、用量与客户端

- **统一管理员权限**：super_admin／admin／user 的平台角色策略、模块与字段授权由后端统一管理；成本、退款、账号授权、导出与敏感正文分别控制。供应商角色采用独立供给范围。
- **用量与导出**：管理端和用户端提供明细、模型分布及 API Key 排行；统计快照、水位、取消和有界导出保留，用户端不泄露上游账号成本。
- **诊断与客户端配置**：保留可计费的 Codex 检测、定时任务、取消和模板；API Key 使用说明提供模型目录与配置下载，Claude／Codex 会话恢复工具及图片技能按品牌配套提供。

## 优化改进

- **统一账号调度**：收敛旧实验开关和手调权重，按资格、真实容量、健康、优先级、订阅偏好和成本档选择；保留现有经营偏好及已经完成的迁移结果。就绪账号优先于满载等待，显式优先级不被成本评分反转。
- **大账号池与冷缓存**：会话、窗口费用、RPM 和负载采用批量读取与有界预热，为最终资格检查预留访问额度；候选跨层保留机会，避免少量忙账号造成全池不可用误判。
- **统一整轮恢复预算**：同账号、同账号切模式和换账号共用尝试次数、绝对首输出期限、退避与存储访问预算；默认最多 8 次生成尝试、同 owner 跨模式最多 3 次，避免多层重试相乘。
- **BPS→原生阶段恢复**：先尝试合格 BPS 候选，阶段预算或候选耗尽后再进入原生 Codex；有合格原生候选时预留生成机会，进入原生阶段后不反复切回 BPS。
- **WS 会话连续性**：可恢复失败结束当前 response 后可继续接收下一轮，每轮重新鉴权、验资格并固定计费及上游归属；失败输入、身份和用量不会污染后续轮次。
- **实例过载保护**：复用实例资源采样，持续高负载时拒绝新请求并返回明确重试信号；已开始的流继续处理，过载不触发换号或账号健康扣分。
- **Ops 调度证据**：展示候选、排除、占位、尝试、耗时与停止原因；诊断条数和大小受限，不记录凭据、正文或会话标识，不把本地决策当作真实上游错误。
- **前端响应与多语言**：列表和核心状态不等待慢统计，切换条件与卸载取消过期请求；供应商门户保留四语、深色模式、窄屏导航和复用的账号／代理组件。

## 问题修复

### 请求恢复与调度

- 修复同账号重试重新进入普通选号而失去真实目标的问题；每次恢复重新占槽并复核账号、供应商、模型、授权模式与出口。
- 修复上游 WS 建连失败直接终止 HTTP 入站请求的问题；满足等价协议和上下文条件时可在同账号回退 Responses HTTP。
- 修复 401 并发刷新重复轮换或旧拒绝撤销新授权的问题；按被拒 grant 版本单飞刷新，停用或归档账号不因刷新成功恢复发送。
- 修复候选删除或重排导致随机权重移位、连续故障账号反复获选的问题；以请求种子和账号 ID 保持稳定抽样关系。
- 修复满额旧会话误拒、未知会话容量当作空闲、原子确认失败继续发送等问题；失败清理只释放本请求创建的资源。
- 修复健康反馈使用错误模型、跨 WS 轮次状态污染，以及把客户端取消、内容策略、实例过载或预算耗尽计为上游故障的问题。
- 移除用上一条 503 清空排除集而反复打开失败账号池的路径；DB／Redis 依赖失败采用有限重试和明确停止原因。

### BPS、工具与计费

- 修复图片 auto_compact 因旧 off 缺省未激活、最终只返回笼统 32 MiB 错误的问题；关闭压缩时明确说明策略及开启位置，不静默删图或绕过预算。
- 修复对独立 reasoning／compaction 密文一概禁止恢复的过宽判定；仅在明确未生成的 BPS 429 等已验证条件下原样重放完整输入，私有引用、嵌入密文、歧义工具或未知执行仍禁止迁移。
- 修复 BPS 限流污染原生 Codex 额度、双授权恢复资格与 WS 实际失败归属不一致的问题。
- 修复先丢弃零文本响应再丢失真实输入／缓存用量的问题；已观察用量立即保留，恢复不能重复记账或拼接已发送内容。
- 修复原生 Claude、Bedrock、Gemini、Antigravity 内部重试未统一检查托管工具副作用的问题；尚未收到文本不代表工具没有执行。

### 供应商、权限与安全

- 修复父子资源汇总重复计数、范围切换返回错误归属以及父级停用后缓存仍可调度的问题；父级恢复不会清除子级自己的暂停或归档。
- 修复授权模式变化、OAuth 刷新与最终上游发送之间资格不一致的问题；实际用量记录真实授权模式，保留供应商分组与出口边界。
- 修复合同价／版本由前端伪造、并发创建越过父级额度及旧归档账号继续被管理写入等边界。
- 保留可信客户端 IP、跨租户响应归属、图片下载公网出口与重定向校验、Grok 语音并发／音色归属及错误凭据脱敏。
- 统一 Claude 已验证的 Linux/arm64 请求指纹、CCH、HTTP/1 格式与会话身份；代理 TLS 继续校验证书，未知版本不携带过期签名。
- 修正 Ops 健康分、请求体过大与账号池耗尽的 SLA 归因，排除软删除分组并保留平台汇总；不因清理历史而改写原日志。

## 行为变化与升级提示

- **同号重建**：本次三个渠道均为 0.2.17.1；已运行旧 0.2.17.1 的实例不能仅凭版本号判断是否更新，应核对源码 SHA 与 release-manifest.json 的镜像摘要并重新拉取。KDAN 旧 0.2.17.3 按本次明确要求统一为 0.2.17.1，不代表回退源码。
- **账号调度设置**：旧算法开关与权重退役，原有效经营偏好经启动迁移保留；已完成迁移不会再次覆盖管理员调整。备份缺失且无法证明安全时会明确停止，不猜测默认值。
- **恢复边界**：已经发送语义内容、工具执行不确定、私有引用不可迁移、权限失效或明确安全拒绝时，不进行盲目换号重放；不承诺所有故障都能生成成功回答。
- **供应商升级**：275 为调度相关迁移，276／277 为供应商角色、层级与双边结算迁移。启动前备份数据库，核对旧供应商登录关系；原消费用户与供应商身份隔离，旧历史用量不凭当前层级虚构新增应付。
- **独立门户**：使用供应商门户需要配置独立 HTTPS Origin 并部署门户前端；仅更新主站镜像不会自动创建 DNS、证书或独立站点。
- **图片与压缩**：已有显式图片策略保持，开启自动压缩可能产生真实上游用量；工具和图片历史仍受原大小、归属及取消约束。
- **官方模型变化**：ChatGPT 订阅账号已退役的 GPT-5.5 不能继续作为默认可用模型；请检查显式映射，API Key 账号按其实际能力使用。
- **品牌与数据**：KDAN、TapModels、Tokensavy 使用各自发布渠道和镜像；升级只替换对应应用，保留数据库、Redis、域名、反向代理和持久化卷。
