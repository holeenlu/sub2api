本次更新集中修复 Claude 请求兼容性和 BPS 加密任务的报错提示。

## 问题修复

- **Claude 请求兼容性**：统一使用已验证的 Claude Code 2.1.301 Linux/arm64 请求特征，修正 CCH 校验字段与 HTTP/1 请求格式；账号连接测试同步采用相同规则，代理连接继续验证 TLS 证书。
- **Claude 会话与请求标识**：协调提示词、会话和请求中的身份信息；对于无法识别版本的客户端，清除可能过期的 CCH 信息，避免转发不一致的校验数据。
- **BPS 加密任务提示**：HTTP 和 WebSocket 请求遇到加密的任务分配数据时，错误信息会指出对应字段路径，并提示使用明文任务数据重试，便于定位和恢复。

## 升级注意事项

- Claude 请求特征固定为经过验证的版本。此更新涉及网关向上游发送请求的格式，账号连接测试与实际调用使用一致规则。
- BPS 的加密任务数据仍不能直接解析；本次改进的是失败定位和恢复提示，需按照提示提供明文数据。
