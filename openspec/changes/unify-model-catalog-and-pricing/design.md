# 统一模型清单与价格设计（最终版）

日期：2026-10-01。本文替代本变更中已经弃用的多策略开放、排除规则、固定账号来源、本地 JSON 和目录 JSON 维护方案。

## 业务合同

1. `/admin/model-catalog` 是候选清单维护，不是授权中心或定价编辑器。可筛选、补充、编辑、停用型号，手工同步，开关自动同步。
2. 分组从清单勾选开放型号，空名单拒绝；账号勾选可提供型号，空名单接受全部。不再区分 fixed/follow，也不再提供排除列表。
3. 密钥目录是分组选择、账号供应与有效路线的交集；还需满足协议与计价要求。清单新增不能自动扩大分组权限。
4. 价格由现有渠道/分组管理。价格目录自动同步，缺失值与显式零价分开，按请求固定价格版本。

## 分层与数据所有权

- 上游适配器：发现 ID、能力、原生 Codex 资料和生命周期，保持凭据范围隔离。
- 持久发现层：快照、同步任务、租约与重试；读取不触发外部请求。
- 候选维护层：对发现结果叠加人工清单，复用 `model_catalog_registry`。逐模型更新在数据库事务中加行锁；停用标记持久保留，同步不覆盖。
- 业务选择层：分组 `model_allowlist.models` 与账号 `extra.model_catalog_policy.models`。名称映射仅负责路由。
- 有效目录层：统一供 `/v1/models`、Codex、模型广场及请求准入使用。Codex 只输出对话型号及可证明的能力。
- 价格层：原始参考价独立于销售覆盖与倍率；保留历史价格和核算证据。

账号、分组选择器读取相同候选来源，支持图片和视频。停用候选不回写已有权限；关闭服务需修改名单或账号调度。上游明确停服/撤权仍优先于人工供应声明。

## 清理边界

移除模式/排除项的类型、运行时策略分支、可见性授权缓存、独立策略写入接口、策略对比、快照回滚、原始模型/价格 JSON 编辑入口与相应测试、翻译。保留必要的来源元数据、同步保护、历史账单及旧数据读取适配；不删除已发布数据库迁移和审计记录。

旧 fixed/follow 都以已保存选择执行，旧排除字段不再解释。旧账号没有独立名单时保留原映射读取，保存时转为独立选择。存量关闭白名单的分组保留原行为，当前编辑器保存时启用所选名单；不通过打开页面隐式写入。

## 故障恢复约束

- 固定供应声明不依赖发现接口短时可用性；认证失败、明确停服/撤回仍拒绝。
- 调度目录范围校验必须使用完整账号凭据和代理上下文；精简缓存通过批量完整缓存补全。
- token 刷新失败可使用已有 access token，由实际响应判断有效性。
- 关闭自动同步不重启旧价格轮询，手工同步保持可用。
- 生产部署和数据库修改独立授权，本次本地重构不代表生产恢复。
