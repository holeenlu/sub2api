## 必须通过的最终场景

- [x] 无源码型号枚举的虚构新模型，通过模拟上游增加即可自动发现；无代码修改、无服务重启。
- [x] 资料与价格齐备且策略允许时，普通 API、Codex 目录与广场按各自协议得到一致模型身份。
- [x] 对新型号执行模拟流式/非流式请求，路由模型、推理档位、模态和结算价正确。
- [x] 上游修改同一型号能力与价格，仅发布数据修订即可生效；人工覆盖、零价和进行中请求价格不变。
- [x] 固定白名单不会自动扩权，跟随策略不会越过账号权限；Key 变更不读取其他 Key 的缓存。
- [x] 资料/价格源落后、429/5xx、超时、无效数据或重启不清空正常目录；明确撤销立即生效。
- [x] 本机更新失败保留可用文件；旧默认模型被撤销时明确提示，不伪造权限或修改历史会话。
- [x] 后端受影响包和必要集成/race 检查，前端组件、类型、构建和多语言检查通过；生产可用性另行验证。

实现取舍：持久目录直接读 PostgreSQL 发布指针，使用请求内缓存与既有账号/渠道缓存失效链；没有新增独立 Redis 目录缓存。`RestrictModels` 保留为等价兼容规则；存量分组不会自动切换到新准入。原生 Codex 缺字段时暂不发布该客户端条目，普通协议仍按各自就绪状态处理。目录大幅减少阈值可配置，价格源继续使用既有校验/告警和独立版本记录。
