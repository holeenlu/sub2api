## 已复现的代码问题

1. reasoning 的 `encrypted_content` 省略及 null 能通过，空字符串却报 `encrypted history content`。编译器和注入器已有“无密文 reasoning 不注入”的语义，本次将空字符串统一为该语义。公开历史保留原值；非字符串仍拒绝，compaction 必须有非空内容，非空密文不改写。此修复针对同文错误的可复现形态，不把缺失原始载荷的历史五条错误全部认定为同一形态。
2. 成功适配日志造成 WARN 噪声。调为 DEBUG；失败适配继续记录到既有 Ops 事件。
3. 无字段适配的本地错误会提前退出诊断记录，原因码可能只存在于内部异常。现在在无 decisions 时也保留闭集 reason 与安全参数路径，不存入指令、工具参数、密文或任意上游文本。
4. Cloud 的提前错误写出把 SSE 心跳误当成业务响应，导致具体错误被公共兜底替换为泛化错误。允许仅有公共心跳时复用公共 `response.failed` 终态，真实内容或已有终态不重复写出。

上述是共享网关修复，无新增授权、产品开关、API 端点或 SQL 迁移。没有增加图片模型白名单、独立调度、跨账号盲目重放。
