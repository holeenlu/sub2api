# vm2api 六项能力复核补齐（2026-10-21）

## 来源、归属与实现语言

参考 dofastted/vm2api `33e1f0a6158f0363d1816bcee9223cc134a3098f`。六项相关源码与审计快照 `a297c8417c73647f0885a879820fd2c23ddf1016` 相同，后续提交只改备份管理。实现属于三个品牌共享能力。

采用本项目 Go 后端、Vue/TypeScript 前端。提示词文本和预设是静态 JSON 数据，由 Go embed 与前端共同读取；额度默认值及校验边界也只有一份 JSON。没有增加 vm2api 的 Node 服务、MJS 模块或运行时依赖。曾用于离线提取的临时 MJS 已删除，静态资源用仓库外 Go 工具重新导入。来源提示词保留原许可证和 NOTICE，不以“独立实现”为名改变原文本的许可。

## 已补齐的调用链

| 范围 | 现有路径中的变更 | 边界 |
| --- | --- | --- |
| 风控 | distillation 读取 system / instructions / developer 指令及本轮用户文本；风险控制页增加“保存并启用”，先保存规则，成功后通过现有设置 API 开启总闸 | 语义审核及拒答记忆继续只读取规定的用户内容，工具结果与 assistant thinking 不加入蒸馏扫描；总闸失败会明确提示，普通保存不改变总闸 |
| 提示词 | 完整预设分开 billing、identity_cli、reporting、agent_official、内部边界、env_official、caller_system；使用来源完整 agent/continuation/environment 文本；未知模板变量保存和渲染均拒绝 | 边界标记不发送；无 caller 时 5 个有效块及两个 1h 标记，有 caller 时保留其原始块；旧 blocks 不自动改写；zero 仍为空数组 |
| 协议 | Anthropic thread 请求补所需 beta，按上一条 message ID 合并同账号同模型的 flags；Responses WS 接受 response.interrupt 并立即确认 | 账号显式头覆盖、beta 丢弃策略保持最终优先级；interrupt 复用 cancel 和用量收尾，不引入第二条生成路径 |
| 换号 | 在真实出站请求构建前校验 thinking / redacted_thinking 的账号归属；在既有 SSE/nonstream observer 收集签名 | 同号保留；异号/未知且有明文转 text，无明文丢弃；工具参数和消息控制字段保留；存储故障保留原请求，交给原错误修复路径 |
| 调度 | 临界额度的候选过滤、最终账号复核和原生分布式信号量读取同一份热更新策略 | 并发收敛至 1；既有候选排序、粘性、排队、响应所有权及 BPS 规则不变 |
| 额度 | Anthropic 默认/Pro 与 Max 分开 5h/7d 停调线；临界带、大冷输入、采样有效期可配置；和 OpenAI 自动停调共用既有 Ops 配置/缓存 | 不越过管理员停调线；Fable 独立阈值保留；账号明确覆盖优先；可信采样、成功缓存证据和自动用卡例外继续按原生规则判断 |

新增签名/线程状态放入现有 GatewayCache 的 Redis 实现，复用现有连接和生命周期。签名首次写入归属不可被另一账号覆盖，30 天 TTL、读取满一天续期、最多 100000 条；thread pin 24 小时、最多 10000 条。键包含用户/Key/组的摘要，账号归属包括凭据身份摘要；不存原始签名、令牌或提示词。更换账号、模型、租户不会继承 thread pin。过期签名视为未知，缓存不可用时不臆测归属。

WS 的 interrupt 会沿用 event_id / stream_id 关联字段；空闲、旧 response 或其他 lane 只确认，不取消其他请求。确认期间进入下一轮时丢弃旧 interrupt。未取得 response ID 时只确认并终止当前生成；已经取得 ID 时沿用原 cancel terminal / usage drain。原 response.cancel 契约继续保留。

## 配置、参数及生效条件

运维高级设置新增 `quota_protection`，作为原 Ops 文档的子结构保存：

| 字段 | 初始值 | 含义 |
| --- | --- | --- |
| anthropic_tier_thresholds_enabled | false | 套餐双窗口策略总开关，显式启用后使用下列四条线 |
| anthropic_default_5h / anthropic_default_7d | 85 / 80 | 默认及 Pro 账号百分比 |
| anthropic_max_5h / anthropic_max_7d | 95 / 95 | Max 账号百分比 |
| critical_band_percent | 5 | 距有效停调线的临界区宽度，单位为百分点 |
| large_cold_input_tokens | 100000 | 临界区可拦截的未确认缓存输入大小 |
| guard_large_cold | true | 是否执行大冷输入拦截；关闭不取消并发收敛 |
| sample_max_age_seconds | 300 | 同凭据、同窗口可信用量样本最长年龄 |

“应用 vm2api 建议值”显式启用套餐策略，并将现有 OpenAI 5h/7d 全局自动停调设为 85%/80%，随后仍需保存。账号覆盖和 OpenAI 自动用卡规则优先级保持原状；该按钮不修改所有账号的用卡选择。Anthropic 套餐取账号凭据的 subscription_type / billing_type / seat_tier；无 Max 证据按默认档。更严格的全局停调线继续取较小值；账号明确 100% 覆盖仍表示停用这条主动保护。

配置更新通过现有 Ops 写入钩子立即刷新当前实例；其他实例沿既有缓存周期刷新。晚返回的旧读取不能覆盖刚保存的新值。旧完整配置缺字段时加载默认值；旧版管理客户端的部分 PUT 保留未提交字段。无需新增数据库表或迁移。

启用顺序：
1. 部署包含本轮实现的版本。
2. 风控页检查组/模型范围、规则及远程审核所需凭据，点击“保存并启用”。keyword_only 继续不依赖远程模型凭据；未配置远程凭据时不能声称远程语义审核已生效。
3. Claude 提示词编辑器选择并保存新的完整预设。已有自定义 blocks 保持原选择；保存时会拒绝未知占位符。
4. 运维设置应用建议额度值或填写明确策略，保存；核对各账号覆盖、套餐信息及自动用卡选择。

发布代码不会代替这些配置操作；本轮没有生产部署或生产设置写入。设备包导入遥测仍遵守 [账号遥测](ACCOUNT_TELEMETRY.md)，不恢复服务器 CLI 初始化或客户端样本采集。

## 保留的本地规则及实际差异

vm2api 自带 routing.json 的换号 3 / 同号重试 3 / 每次 500ms / 总发送 12 / 120s 恢复期限，不直接覆盖本项目现行参数。本项目保持换号默认 10、同号上限 3、基础 500ms；整轮实际发送硬上限 8，首输出普通 300s / 高推理 600s，重试等待累计上限 10s。以实际运行配置及平台路径为准，不把这些参数叫作等值移植。

不引入 VM SeatPlanner、宿主共享 refresh-token 文件、服务器 CLI 初始化、weekly_split 实验、超过管理员线的 overshoot。冷输入估算和缓存证据范围仍采用本项目实现，不承诺每个请求判断、池吞吐、缓存命中率或上游风控效果和 vm2api 完全一样。

删除被替代的前端硬编码预设/变量清单、后端 agent_official 指向本地扩写的别名和硬编码额度常量；现有扩写变量仍供已保存的自定义配置使用，有明确存量调用契约，不能当作失效兼容路径删除。新目录承载来源静态资产，状态与配置辅助文件由原请求/缓存/设置入口调用；没有平行网关、调度器或周期任务。

新增公共 HTTP 路由 0、迁移 0、运行依赖 0。新增内部缓存能力接口 1 个（2 方法），Ops 子配置字段 9 个，模板变量新增 3 个（identity_cli、reporting、dynamic_boundary）。新增行为路径按触发点计 4 类：指令范围蒸馏、签名归属过滤/采集、thread beta pin、interrupt 控制；其余是现有模板、配置及额度路径完善。
