# Codex 模型目录与默认配置

当前实现以 [模型目录与价格同步](MODEL_CATALOG.md) 为准。

- `/keys` 使用服务端按当前 Key 生成的 setup profile，打开弹窗立即生成配置，不等待上游请求。OpenAI 分组默认选中 Codex CLI (WebSocket)、API Key Mode、macOS / Linux；重新打开或切换密钥恢复默认选项。
- 配置在 provider 内写入 `model_catalog_url = "<站点>/v1/models"`。客户端使用当前 Key 读取分组有效目录；需要 Codex 0.156.0 及以上。该接口在客户端携带 `client_version` 时返回 Codex manifest。
- 「检查连接 / 查看此 Key 可用模型」只读取本站目录，可查看具体型号并再次检查，不是配置前置步骤，不触发上游模型刷新。
- 2026-09-30 起停止支持旧客户端。本地 `model_catalog_json` 配置、`codex-models.json` 下载及 Python 更新脚本均已移除；已有用户需升级客户端并重新复制配置。认证方式中的 `auth.json` 是登录凭据文件，与已移除的模型目录 JSON 不同。
- 模型事实、能力和价格由服务端目录任务同步并保存。上游新型号资料完整、账号与分组允许且价格完整后可发布；不复用其他型号的能力，也不把缺价当成免费；管理页面以候选清单维护为主，不展示原始能力 JSON。
- 模型清单集中维护候选、显示名、类型及停用状态，保留手工同步和自动同步开关。账号白名单声明供应（留空全部接受）；分组白名单决定对密钥开放的范围（留空不开放）。刷新只更新候选和能力资料，不改变两层勾选；别名路由和定价由原管理入口负责。
- 远程目录超过客户端 1 MiB 限制时提示管理员减少分组开放范围，不回退到旧文件模式。
