## 新增功能

入口：**智能运维 → 自动 BPS**（`/admin/account-quality`）。在规则列表勾选一条或多条规则，点击“删除所选规则”；也可以在规则编辑区单独删除。**无需配置，部署后自动生效**，不会自动执行删除或启用规则。

- 确认框固定展示账号名和规则 ID；确认后只处理这份清单，后续选择变化不会扩大范围。
- 逐条调用既有 `DELETE /admin/scheduled-test-plans/:id` 接口，不增加批量删除后端接口。
- 失败不阻断其他所选规则；展示各失败 ID 与原因，重试仅发送失败项。
- 执行中防止重复提交；注销、切换身份或离开页面后停止发送后续删除。已经发出的请求可能完成，不宣称可撤回。
- 每次成功即从页面移除该规则、相关探测记录和已加载详情。刷新失败或旧详情响应晚到，也不会恢复已删除内容。

## 兼容与运维

删除规则通过现有数据库外键级联删除其探测记录和规则状态。删除不回滚账号当前 BPS 配置；如需关闭 BPS，应在 **账号管理 → 编辑 OpenAI OAuth 账号 → Excel / BPS**（`/admin/accounts`）中设置。确认框已说明该行为。

既有后端删除范围仍限制为连接测试或自动 BPS 状态探针；页面只列出自动 BPS 规则。没有新增数据库迁移、环境变量、依赖、调度选项或上游探针请求；自动 BPS、403 恢复、账号 RPM、资格校验和独立成本倍率保持原实现。
