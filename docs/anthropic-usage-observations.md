## 需求沿革与本次清理

最初新增的逐字段详情、来源徽标和档位展示已被上述紧凑展示替代。本次按主工作区 AGENTS.md 的“需求变更与旧代码清理”复核其完整调用链：

- 之前已删除 AnthropicUsageDetails.vue、UsageObservationBadge.vue 及详情组件测试；本次删除剩余被动采样文案、未用类型和授权详情投影。
- 移除用量查询附带的自动 Profile 请求、Profile 档位/资格解析、额外使用原值、overage 详情、原始 limits 列表及无消费者的 Opus 观测。限额状态不再因正常的额外使用开关产生提示。
- 保留 limits 的输入解析，只将无范围的总体窗口、唯一的 Fable/Sonnet 模型窗口规范化。未知或重叠范围不映射成全账号额度，不保存用于详情展示的描述符。
- 删除仅测试使用的无元数据写回、无 JSON 存在性转换、旧 FetchUsage 包装及可选 Fable 统计兜底。测试改为走生产 JSON/规范化路径。
- 删除第二套窗口构建及凭据校验后再次读取 Fable 旧快照的分支。管理员、供应商及被动读取共用规范化窗口投影。
- 删除后台重复费用估算；继续使用账号单元格中与 OpenAI 共用的估算函数。
- Profile 字段猜测不作为封禁依据。提示仅接受现有网关和用量请求的实际状态、明确拒绝原因及仍有效的限额采样。

本次不是撤销 Anthropic 用量、持久化、异常提醒或 Claude 重置功能。

## 存储、回传与数据处置

保留的上游观测仍写入账号 Extra 的 anthropic_observation_* 键，每项带凭据归属和独立采样时间。活动字段白名单由同一函数控制读写，退役的档位、额外使用、原始分窗口等旧键不再参与观测、回传、异常判断或窗口构建。

账号列表/详情的 Extra 不直接暴露内部观测及归属指纹；用量 API 和状态投影提供需要的数据。普通账号编辑保留已有内部观测，阻止表单新增或篡改观测；专门采样路径继续更新活动字段。复制账号不继承观测。

本次没有连接或删除生产数据库、缓存历史记录，没有迁移，也没有修改已应用迁移。历史 JSONB 旧键可能仍存在，普通账号编辑只保留其原有值以免未经授权删数据；如需物理清除，须单独核验并授权迁移。不能把停止业务读取称为数据库数据已清理。

## 验证边界

### 重置后窗口同步（2026-10-20）

重置成功后，按上游结果的 cleared 列表保存对应窗口的 cleared_at 观测（沿用凭据归属、来源和采样时间）。seven_day_overage_included 对应 7d F；仅返回 seven_day 不代表 Fable 也已清零，失败、未知结果与幂等回放不再次清零。

该标记使重置前的用量/限额观测、旧 API 缓存与在途查询失效。新的实测优先；缺失 Fable 字段的主动查询不能回填重置前的被动快照。上游未提供新截止时间时，不沿用旧倒计时或编造新时间。本地窗口统计从正常窗口起点与已确认重置时间两者较晚者开始，保留历史 usage_logs；不同窗口独立处理，7d 全量查询仍包含 Fable。

现有利用率和截止时间无法区分“旧请求晚到”与“重置后的新窗口”，因此在已有观测映射内增加这一受管字段，不新增 HTTP 接口、配置或外部请求。账号用量组件的主动刷新同时更新现有缓存，并拒绝刷新前的迟到响应；不增加页面文案。真实上游窗口、调度标记和重置券是否包含 Fable 仍以实际返回为准。

这一修复只对部署后收到的明确重置结果生效；没有凭据归属与重置证据的历史快照不会被猜测性清零，仍须由新的上游用量观测更新。
