# 模型广场：分组目录与报价

`/model-plaza`、文档中的分组模型/价格和客户端模型目录共用 `GroupModelCatalogService`。Codex 配置里的 `model_catalog_url` 只是客户端读取本站目录的地址；它不是服务器模型广场的配置入口。

## 配置入口

1. **账号管理**：将账号绑定到分组，启用账号与调度；配置公开请求名到上游模型的映射。API Key 透传账号使用发现快照或分组显式选择，残留的账号映射不用于声明可用模型。
2. **分组管理 → 模型白名单**：限制公开模型。具体选择可以声明请求名；通配符只筛选已有具体候选，不能生成虚构模型。列表保留选择顺序。
3. **复合分组 → 路由**：配置公开别名、目标平台、端点和上游模型。相同别名在不同端点可有不同报价；平台归属冲突会进入诊断。
4. **分组价卡 / 渠道管理 / 全局计费目录**：配置计费价格。价格解析沿用现有计费服务。仅增加价格记录不会自动开放模型；缺少价格也不会隐藏已配置支持的模型。
5. **分组管理 → 模型预览**：查看实际目录、分组标准价和排除原因。预览是只读管理员接口，不受公开广场开关影响，不包含个人倍率。当前支持启用中的分组。

公开广场仍遵循已有站点开关、登录要求、专属授权、订阅及公开分组限制。先判定用户可见性，再读取对应组的账号目录；响应使用 `Cache-Control: private, no-store`。

## 目录来源和发现状态

候选来源包括账号显式映射、成功发现的具体模型、渠道映射、精确复合路由及分组具体选择。通用产品元数据、内置默认列表、价格目录都不能单独声明生产开放。

普通分组按平台隔离；复合分组按真实路由规则解析。渠道映射、通配价格限制、账号映射、分组模型准入及生图开关共同裁剪结果。临时冷却或负载不会使名单反复变化；持久禁用、关闭调度及自动过期账号会被排除。目录声明配置支持，不是推理接口的实时健康探测。

OpenAI `/models` 和 Codex manifest 成功发现后保留进程内安全投影快照。匿名浏览不请求上游。超过 15 分钟标为 `stale`，超过 24 小时不再采用；账号凭据、来源、映射、代理或透传设置变化使对应快照失效，影子账号同时检查母账号凭据。用量和能力元数据更新不会误使目录失效。重启后需要重新发现，可在账号管理刷新模型列表或由正常客户端目录请求完成。其他平台通过显式映射/同步后的配置声明模型。能力元数据快照可能只包含部分模型，因此不将其当成完整开放名单。

启用“指定来源账号”后只采用这些来源的成功快照；有效空目录保持为空。来源快照不完整时显示 `unavailable`，不以默认模型或价格记录补齐。原 OpenAI/Codex 上游协议响应保留元数据、ETag 和既有回退行为；广场遇到缺少可靠快照时会明确显示不可用。

## API 与价格含义

`GET /api/v1/model-plaza` 保留旧字段，新增：

- 分组：`catalog_status`、`catalog_updated_at`、`personal_quote_unavailable`。
- 模型：`endpoint` 与 `quote`。
- 报价：`status`（resolved / conditional / unavailable）、`scope`（group / personal / group_fallback）、`source`、`basis: standard_period`、`unit`、`rate_multiplier`、`pricing`、`conditions` 和可选 `image_token_pricing`。

旧 `pricing` 仍为未乘分组/个人倍率的基础展示价；**`quote.pricing` 已应用有效倍率，客户端不可再次乘倍率**。时间区间行按已披露的时间系数展示，高峰、推理等级、上下文档位等条件保留。个人倍率读取失败时返回明确的分组参考价状态。`0` 表示明确零价，`null` 表示没有可用报价。

Token 和图像 token 单价内部为美元/token，界面换算美元/百万 token；按张、按次、按秒不作这一换算。图像输入、输出、图像缓存使用真实计费字段独立计算。视频展示分辨率档和秒单位，媒体独立倍率沿用原计费选择规则。多个计费身份、响应模型决定计费或不同规格存在不同计费单位时，返回条件报价而不是猜测单价。

参考列为“目录参考价”，可能来自全局计费目录或兼容价格，不代表独立核验的官方价格。映射到另一计费身份的别名不冒用该身份的官方名称。

管理员只读接口：`GET /api/v1/admin/groups/:id/model-plaza-preview`，返回 `{ group, issues }`。诊断包含纯价格条目、策略排除、路由冲突、无可用配置、无发现快照及未展开通配规则；公开接口不返回诊断或账号/凭据信息。

## 客户端和文档

普通 `/v1/models`、单模型查询及生成式 Codex 目录采用共享模型集合。OpenAI 配置型 Codex 目录使用相同集合，已有发现型 manifest 保留协议元数据后按共享集合过滤；指定来源分支继续保留原语义。Codex 目录另按协议要求排除专用媒体模型及未显式启用的自动模式。

文档价格组件直接复用分组报价组件，模型列表不再在目录不可用时回填静态开放名单。静态模型资料仅用于说明能力。广场、首页和文档在退出登录、切换账号或组件卸载时取消旧请求并清空旧数据。

## 验证与上线

无需数据库迁移，也没有新增必须配置的环境变量。合入并部署后，管理员可先在“模型预览”核对各组名单；依赖发现的来源先刷新目录，随后验证匿名、普通用户和专属用户三个视图。此变更不修改现有模型/供应商配置，不触发部署、发版或生产数据写入。
