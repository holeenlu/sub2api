## 新增功能和配置

入口：**账号管理（`/admin/accounts`）→ 添加/编辑 OpenAI OAuth 账号 → RPM 限制**，支持批量编辑。存储键 `account.extra.base_rpm`，后端未配置或 0 不限制；保留已有值，不批量开启账号限额。开启表单但未填有效正数时采用源功能默认值 15。

- 只作用于 `platform=openai,type=oauth`；同账号原生 Codex 与 Excel / BPS 使用同一个计数。不会给独立 `openai_bps` 平台、OpenAI API-key 或其他供应商新增此限制。
- 自然分钟窗口，Redis TIME + Lua 原子检查/递增；超过上限的请求不再增加计数，跨分钟重新开始。80% 用于调度余量/预警，100% 为硬上限。
- HTTP、WebSocket 多轮、BPS 主请求/重试/工具修复、实际附件上传、BPS 管理员探针均在实际上游发送边界计数。已尝试发送但失败仍计数；本地参数/资格校验失败、发送前取消、附件缓存命中不计数。
- 影子账号与父账号共享计数，不能通过自身关闭或提高数值规避父账号正数上限；父子有效正数上限取更严格值。`effective_rpm_limit` 展示生效值，不改写影子账号保存的设置。
- 正常限流使用 429 与 `Retry-After`；严格计数服务不可用时使用 503。未配置限额的合适候选继续可用；上下文不允许换账号的续接请求仍保留原有绑定约束。

## 相对源提交的必要适配

1. 源 handler 的提前扣额改为只读检查，原子扣额移到实际发送，避免本地拒绝误扣；首次发送不重复计数，不复用过期预留。
2. 原生 HTTP 接入本地 `openai_plugin_transport.go`，依赖注入使用 `wire_codex_ticket.go` 与原有构造器，不导入 fork 的代理/工厂体系。
3. BPS 生成统一在 `doExcelBPSSend` 接入；附件仅在缓存未命中的实际上传处接入。组织限流有界重试、工具修复和再生成分别重新检查，RPM 错误不误报为上游连接失败或污染账号健康。
4. BPS 使用原有发送前主库核验返回的最新账号政策，不移除资格检查；影子账号解析父账号政策失败时不能绕过限制。
5. Redis 失败时剔除需要严格保护的候选，让其他合适账号继续参与；可迁移请求可以离开受影响的粘性账号，不完整的续接上下文不能擅自换账号。
6. 新增影子账号的有效限额展示、日文和生成的繁体文案，保留当地时区、TLS、品牌设置及既有 Anthropic 策略。

## 运行边界

RPM 是本地账号发送次数保护，并非上游模型配额账单，不限制每次 token 数，也不提高组织 TPM、图片数量或图片中转并发上限。附件真实上传按本次批准的本地请求口径计数。部署后需管理员主动设置账号 RPM；既有正数设置继续生效。公共/品牌分支不因本次合并自动推送或发布。
