移除范围包括：BPS/Excel、DeepSeek × Codex 和 Copilot 特殊适配、banana 图片模型、fork 的连接重试与代理回退、Cyber 按会话 ID 屏蔽变更、账号分组倍率、分组模型限制与仅流式分组、请求耗时明细/TPS、鹈鹕测试与展示、质量运营/账号告警、凭证守护、管理员请求采集、定向用户公告、观察员权限及后续 fork 增量。

保留原有原生 DeepSeek、用户分组倍率、图片任务、插件、品牌配置、发布/升级、本地模型同步及弹窗能力。保留打票生命周期、ModelTrace、代理池、模板、诊断、模型资格限制和插件票据脱敏。

## 升级与数据

历史 14 个迁移文件（241–252，包括两个 245 和两个 249）保持原字节；已经部署的迁移账本继续有效。新增 `253_retire_fork_features.sql`，随应用启动的既有迁移流程执行；本次仅在临时本机数据库验证，没有连接生产数据库。

253 不删除历史数据、配置、凭据或票据，执行以下一次性退役：

- 停用 BPS 账号/分组/模型路由，停用显式 Excel/BPS OAuth 与 Copilot API Key 账号，避免它们自动改走普通协议；关联监控和测试计划同时停用。
- 停用鹈鹕及质量计划，保留计划和结果。仓储持续排除 `pelican_config IS NOT NULL`，防止旧计划被普通连通性测试执行。
- observer 回落普通 user，保留余额、分组和历史授权范围记录。
- 归档带指定用户条件的公告，防止旧编辑器丢弃条件后扩大受众。
- 账号/分组变更通过调度 outbox 生效，既有用户/分组触发器使鉴权缓存失效；鉴权快照版本提升为 27。

退役字段和数据表仅为升级兼容保留，前后端入口及运行服务已移除。原 fork 的账号分组倍率、模型限制、仅流式规则等不再参与请求处理。此前质量策略或凭证守护已修改的账号状态/分组不自动恢复，避免覆盖管理员的后续修改。管理员若要重新使用被停用账号，应先确认普通通道兼容，再手动恢复。

## 打票可靠性

1. 只有收到完整 `response.completed` 且 ModelTrace 验证通过的探针才可写票；断流、只有 `[DONE]`、失败事件、损坏 JSON、超限读取均不得记录成功。完成后立即关闭流。
2. 写票时原子核对凭据、账号资格、参与开关和上次票据 generation。重新授权、停用或更新票据后，旧探针不得覆盖新状态。单模型 JSON 更新保留其他 extra 和其他模型票据；调度 outbox 与写票同事务。
3. 手动打票响应重新读取已持久化账号，返回正确的 ready/代际状态。
4. 自动与手动共享并发上限：最多 4 个，且不超过数据库连接上限的一半。自动扫描使用有界工作队列。`database.max_open_conns=1` 拒绝采票，需至少 2；生产仍应预留正常业务连接。
5. 单次超时覆盖锁获取、账号读取和上游探测。后台配置读取有独立短超时。
6. 数据库会话锁获取/释放结果不确定或清理会话参数复位失败时丢弃连接，避免锁或会话设置污染连接池。

大量账号同时到期时会按有界批次完成整轮探测，因此实际重试可能晚于设置的最短间隔。

原有票据仍依照既有生命周期/刷新设置处理；默认自动刷新周期 1800 秒，设为 0 的既有不自动刷新语义保留。升级后可手动重新打票，以获得新校验链路的结果。

## 验证边界

本轮按用户选择进行本机模拟、真实临时 PostgreSQL/Redis 和并发验证，不使用真实上游账号。覆盖流完整性、旧结果拒绝、同模型竞争、跨模型并发合并、事务回滚、缓存同步、锁故障、超时、迁移升级与历史数据保留；若只读替换回旧实现，相应流/锁回归会失败。

ModelTrace 属于模型分类信号。采票代理池与正常业务代理配置分别生效，本机通过不证明真实上游识别结果、业务出口或实际请求成功率。真实效果仍需授权环境中的少量业务请求验证。

- 打票服务与仓储 race 检测通过；新改动 golangci-lint 为 0 问题。
- Ent、Wire 重新生成无代码差异；包含前端资源的服务构建成功。
- 前端类型检查、ESLint、361 个测试文件/2797 个用例、生产构建、语言键与繁体生成检查全部通过。
