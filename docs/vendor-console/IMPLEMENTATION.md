## 4. 测试执行策略

优先扩展已有 authz、middleware、OAuth state、代理引用/到期、DTO 脱敏、usage repository、scheduler snapshot 和前端表单测试。只为新的跨供应商独立风险补用例，避免用几十个页面测试重复一条后端权限规则。

未来实现后的检查命令从仓库现有入口选择，以下不是本次已执行结果：

```sh
# backend/，先定向受影响包，再完整回归；需要相应临时依赖
make test-unit
make test-integration
make verify-generate

# frontend/
pnpm test:run
pnpm typecheck
pnpm lint:check
pnpm i18n:check
pnpm build
```

真实计费请求、生产迁移和外部供应商资源变更不属于测试默认授权。OAuth/上游通过替身验证；确需真实集成验收时另行记录范围、凭证来源、预期成本和授权。
