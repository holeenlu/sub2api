## 2026-10-17 供应商开通与个人中心复核

按最新供应商控制台截图重新核对正式 Vue 结构和本地原型，补齐了两个此前缺失的入口：

- **新建供应商**默认选择“新建普通用户”，页面只展示登录邮箱、供应商资料、平台/分组和资源配置，不展示密码输入框；说明文案明确密码由用户后续通过原生账号安全流程设置。现有用户表仍要求密码哈希，因此正式保存时由前端生成一次性随机内部初始值，既不展示也不发送给供应商；后续密码仍由用户自己设置。
- **供应商控制台个人中心**加入右上角头像、姓名、邮箱和角色菜单，提供“账号设置”和“退出登录”。账号设置包含“账户信息”和“修改密码”两个页签，并复用项目原生密码、TOTP、Passkey 组件；供应商角色不会因此获得管理员入口。
- **超级管理员供应商平台**补充权限边界、结算范围、历史留存提示、供应商运营摘要卡片和模块图标导航；供应商列表仍使用项目后台接口和现有数据结构，原型只保留虚构数据。
