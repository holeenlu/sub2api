## 配置与操作

- 遥测：运维高级设置开启 forward；账号管理中可选择/清除遥测副本。无副本自动初始化不另设开关。清除副本不会删除原始客户端样本或原账号身份缓存。
- 风控：现有风险控制页；新增默认规则仅用于全新配置，旧配置保持原开关及空规则含义。fingerprints 可填 SHA-256 或文本片段；保留 TTL、容量、白名单、observe 和失败策略。共享存储故障按既有 fail_open/fail_closed 处理，不记为用户违规。
- 模板：现有 Claude system 编辑器。minimal 保留最小身份/约束/环境，zero 为真正无注入；official_full 是本地全文扩写布局，不声称来源官方文本逐字等价。placement 可选 system、overlay_body、overlay_wrapper；match 是可选 Go RE2，仅匹配末轮用户内容，wrapper 必须有 overlay_body 变量。JSONL 导入后仍保存到原 blocks 字段。
- 调度与额度：继续复用管理员 5h/7d 停调线，距阈值 5 个百分点、100k 大输入、5 分钟可信额度采样。正向缓存证据只在成功结果携带缓存 usage 时记录；没有证明就按冷请求处理。已停止账号不会因 warm 证据重新获得资格。
- 修改部署生效后开始使用新代码；本轮不执行部署。没有新增 HTTP 路由、数据库迁移、顶层设置或外部运行依赖。

## 清理

替换了旧“缺副本跳过”业务条件、永久标量歧义缓存和单纯历史豁免；旧绑定键不再读取、按原一小时 TTL 自然到期。清理账户保存宽松校验与发送严格校验的双轨逻辑、实例内专属记忆语义和空块报错分支；更新关联说明、语言文案和测试。不删除样本历史、不改写迁移、不重置管理员保存设置。

新增辅助文件分别承载账号遥测共用解析/初始化、模板运行上下文/overlay、共享风控状态编解码；原函数不能同时承担初始化与共享状态协调，辅助仍由原入口调用，未新增网关入口或并行调度系统。

## 验证与限制
