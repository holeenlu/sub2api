# 运维入口退役说明（2026-09-29）

本次移除 ranxi2001 fork 引入的三套低收益运维功能：

- `/admin/account-quality`：自动 BPS、质量规则、鹈鹕状态探针和质量历史。
- `/admin/priority-scheduling`：独立的利润优先调度配置、快照和批量优先级编辑。
- `/admin/token-guard-v2`：凭证运营、自动重新登录和对应的本地密码守护 worker。

后端不再注册上述路由，前端也不再提供菜单、页面、API 模块或账号创建/编辑时的自动规则写入。普通账号连通性定时测试、现有高级调度器、手动账号重新授权继续保留。Excel/BPS 已于 2026-10-05 移除，Codex 降智检测继续保留。

2026-10-05 进一步移除附带的 OAuth 新账号初始化模板、额外别名模式和独立成本倍率。账号自身的原生模型映射、原有计费倍率和 Codex 降智检测继续保留。

历史迁移文件、旧表字段、已部署的质量计划和结果不删除，以保证升级账本和回滚兼容。旧的 `pelican_config` 计划会被仓储过滤，不能被普通连通性测试执行；新的创建或更新请求带有该字段时会返回“旧质量测试计划已退役”。

本次没有新增数据库迁移，也没有推送或发版。
