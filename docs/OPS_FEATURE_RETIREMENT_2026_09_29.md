# 运维入口退役说明（2026-09-29）

本次移除 ranxi2001 fork 引入的三套低收益运维功能：

- `/admin/account-quality`：自动 BPS、质量规则、鹈鹕状态探针和质量历史。
- `/admin/priority-scheduling`：独立的利润优先调度配置、快照和批量优先级编辑。
- `/admin/token-guard-v2`：凭证运营、自动重新登录和对应的本地密码守护 worker。

后端不再注册上述路由，前端也不再提供菜单、页面、API 模块或账号创建/编辑时的自动规则写入。普通账号连通性定时测试、现有高级调度器、手动账号重新授权、BPS/Excel 协议和 BPS 图片链路继续保留。

手动 BPS 默认参数和 OpenAI OAuth 新账号模型映射仍然有效，入口统一放在“系统设置 → Excel / BPS”。这两项是显式配置，不会自动创建质量计划或改变账号调度。

历史迁移文件、旧表字段、已部署的质量计划和结果不删除，以保证升级账本和回滚兼容。旧的 `pelican_config` 计划会被仓储过滤，不能被普通连通性测试执行；新的创建或更新请求带有该字段时会返回“自动 BPS 和质量测试计划已退役”。

本次没有新增数据库迁移，也没有推送或发版。
