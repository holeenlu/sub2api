## 新增功能

入口：**账号管理 → 编辑 API Key 账号 → 成本倍率旁“跟随上游”**，路由 `/admin/accounts`。后端键 `accounts.extra.cost_multiplier_auto_sync`，默认关闭。原成本键 `accounts.extra.cost_multiplier` 和缺省值 0.1 不变；新开关本身不发请求、不启用自动探测、不启用独立的账号计费倍率同步。

主动开启后，由现有手工探测或自动探测的下一次有效成功结果更新成本。更新包含探测时适用的峰时倍率，允许有效零成本；失败、不支持、无效或超范围结果保持已有成本。探测快照过期不会把已保存成本改回默认值。普通 OAuth/BPS 账号仍采用手填成本或默认值，不新增 OAuth 探测通道。

利润评分入口：**智能运维 → 优先调度**，`/admin/priority-scheduling`，既有设置 `priority_scheduling_v1`。同步只影响其成本估算；不改历史日志、用户余额、用户扣费、账号计费倍率或分组计费倍率。

## 优化改进与 Bug 修复

- 探测后轻量列表 API 返回保存的 `cost_multiplier`；列表即使按名称、最近使用或状态排序也更新该值，不重载整表/统计，不改变无关排序。无需配置，部署后自动生效。
- 编辑表单未修改成本或开关时不发送这两个字段；数据库在现有行锁下保留最新值，防止打开较早的表单回写旧成本。无需配置，部署后自动生效。
- 探测写回使用数据库当前开关；管理员关闭跟随并保存手动成本后，在途探测仍可更新快照，但不覆盖手动成本。保留凭据、代理、快照、探测与计费同步开关的 CAS 比较，以及同事务调度 outbox。
- 重新开启仅改变模式；批量修改成本不改变跟随模式。跟随开启期间手工改成本会暂时生效，下次成功探测仍可覆盖，操作说明已更新。
