# 工作包交接模板

- Task ID / owner / reviewer / review_mode（self_review或independent_review）：
- 源码基线 / 工作分支 / 实际结果SHA或补丁：
- 契约版本 / 涉及REQ与CT：
- 编码规范版本 / 适用CS编号 / 检查证据 / 必要例外与退出条件：
- 目标与实际完成：
- 允许写集 / 实际修改文件 / 越界项处理：
- 公共接口或装配修改申请与消费者：
- 业务代码新增/删除/净变化：
- 测试代码新增/删除/净变化：
- 新对外接口 / 运行配置 / 执行路径数量及必要性：
- 旧入口、helper、字段、配置、UI、文档、测试删除或保留依据：
- 验证命令 / 输入 / 工具链 / 环境 / 实际结果 / 证据位置：
- 未运行或未采集：
- 安全、账务、会话、取消和数据回退影响：
- 剩余阻塞及仅受影响的任务：
- 临时资源归属、清理后实测、必要保留：
- 交接状态：planned / in_progress / review / accepted / blocked。

不得填入token、真实用户内容或无来源的测试结果。代码审查、运行验证和生产验收分别说明。

前端包补充：FR编号、领域公开出口/route与locale贡献、session/scope寿命、app集成路径与实际单写者、旧消费者删除和仍保留URL/存储合同；不可将未接线组件标为切片完成。

- 计划deliverables与实际产物逐项对照；evidence_refs的已执行/未执行/不适用及理由：
- 依赖验收记录、真实消费者接入结果和下一包可消费的接口版本：
