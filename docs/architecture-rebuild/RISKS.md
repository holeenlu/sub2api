# 信任边界与失效风险

本表用于选择实现与验收重点，不新增产品批准流程或运行时开关。严重性基于潜在影响，发生概率尚未测量，不编造风险分数。具体合同见CONTRACTS，验收见VALIDATION。

## 信任边界

| 边界 | 输入与资产 | 应由谁验证 |
| --- | --- | --- |
| 客户端 → ingress | Key、请求身份、模型/工具/附件、continuation | 入口鉴权/大小与协议检查，scope由服务器生成 |
| 控制面 → 配置/资源 | 管理权限、供应商归属、配置revision、凭据 | 服务器RBAC/step-up/审计及领域校验，不能相信UI隐藏 |
| 引擎 → provider | resource/grant/permit、mode、正文副本 | 发出前实时复核，permit一次性且内容绑定 |
| 实例 → Redis/owner | 命令、epoch、续接定位、lease | 实际身份范围、epoch和命令去重；不能用ID存在代替授权 |
| 账务 → PostgreSQL | 费用、配额、供应商成本、usage事件 | 保留幂等指纹和事务边界，拒绝不一致重复事实 |
| provider → 客户端 | 不可信上游帧、工具身份、产物链接 | 协议/归属/出口保护；事实与原文来自同一数据 |
| 插件 → host | 已有插件进程权限、请求/结果 | 保留宿主信任和生命周期边界；本重构不授予新权限 |

## 风险登记

| ID | 风险与严重性 | 设计处理及可观察证据 | 责任包 |
| --- | --- | --- | --- |
| RISK-01 | 并发发送/隐藏重试导致重复工具副作用，严重 | 登记attempt；发送unknown保守处理；提交后不能切换生成；检查实际发送次数与tool身份 | WP-08/09/10/18 |
| RISK-02 | 排队或长连接期间权限变化仍执行，严重 | 每轮及发送前复核scope/grant/lease；撤销与发出非全局原子，明确检查点和取消行为 | WP-03/04/17 |
| RISK-03 | 续接ID串租户/Key或旧owner写入，严重 | 绑定实际身份和epoch；迟到业务输出拒绝，费用事实按幂等合同处理 | WP-05/12/18 |
| RISK-04 | 重复、未知、累计usage误结算，严重 | 旧键映射、累计/增量、持久化pending、同根结算；检查资金双方和quota | WP-06/11/12 |
| RISK-05 | PG故障时只存内存closure丢费，严重 | 明确持久化失败路径及ACK约束；未确认事实不能假装settled，恢复重复安全 | WP-06/08/25 |
| RISK-06 | Redis失效/分区导致容量和owner分裂，严重 | lease有效期与epoch、停止新派发、可恢复与不可恢复分开；不宣称socket透明迁移 | WP-04/05/25 |
| RISK-07 | 转换吞字段或打乱tool id导致行为变化，高 | 原文/事实同源、转换诊断、完整交互夹具与实际客户端证据 | WP-02/09/11/12 |
| RISK-08 | 慢客户端/取消引发无界缓冲和goroutine泄漏，高 | 有界背压/缓冲、取消生产者、资源栈释放、drain与挂起turn分离 | WP-08/17/22 |
| RISK-09 | 配置并发覆盖、半轮换价或旧凭据续用，高 | revision条件提交、策略快照、grant代际、动态撤销 | WP-07/20 |
| RISK-10 | 图片/产物下载SSRF与voice跨用户使用，严重 | 保留已有可信出口、链接和对象归属检查；下载/轮询重新鉴权 | WP-16/17 |
| RISK-11 | 数据/会话格式升级使版本回滚失效，高 | 记录真实旧读者及格式版本，滚动窗口/排空条件；代码与数据恢复分别演练 | WP-05/06/23/25 |
| RISK-12 | 多agent接口分叉或越界覆写，高 | JSON单一任务源，共享合同/装配单写者，交接diff和依赖验收 | 全部、WP-24 |
| RISK-13 | 旧路由仍注册，形成第二执行核心，高 | 退休清单按完整功能核查注册/调用/动态字段，不能只全文搜索旧名称 | WP-10/18/19/24 |
| RISK-14 | 品牌传播/来源改写丢失其他任务成果，高 | 现行三方树、精确lease、恢复备份及并发保护；文档提交不触发发版 | WP-26 |
| RISK-15 | 改展示品牌误改存储、会话、账务或部署挂载，严重 | 三种身份分域，保留稳定键和旧有效配置/卷映射；AT-39/41/43 | WP-20/23/27 |
| RISK-16 | 公开API/Logo设置获得管理凭据、宿主或上游权限，严重 | public投影白名单和既有URL安全，地址分域；AT-42 | WP-20/21/27 |
| RISK-17 | 来源整合重新引入商业推广或误删署名，高 | 用途/可达性审查与最终制品检查；AT-38/43，不按关键词删除许可证 | WP-24/26 |

低延迟、吞吐和内存效果须用同条件基线评估；未测数据列为OPEN-03。风险降低不能靠声称已增加测试数量证明，必须说明失败条件和可观察结果。
