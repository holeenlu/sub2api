## 新增功能与配置

- 账号管理 → 编辑 OpenAI OAuth 账号 → Excel / BPS → 勾选模型（`/admin/accounts`）：显式勾选 `gpt-image-2` 可使用 BPS 非流式 PNG 文生图、无蒙版单图编辑。
- 后端沿用 `accounts.extra.openai_excel_bps` 与 `accounts.extra.openai_excel_bps_models`，无新环境变量。按账号映射后的模型名匹配；空列表关闭路由。
- 默认不启用图片通道；旧「对所有模型启用」不包含生图。Free、影子账号及其他既有限制保留。
- 流式、蒙版、透明背景、非 PNG、多图编辑、远程编辑图片 URL 等不支持参数在发送前走原生 Codex。只允许本地上传或 data URL 单图编辑。
- 上游明确返回请求格式拒绝（400/404/405/413/422）且客户端未收到内容时才允许原生回退；401/403/网络/5xx 不重放。429 保留 BPS 独立冷却及既有账号切换规则，不污染原生额度状态。
- 账号管理 → 测试：图片模型使用相同图片路由，不误发到文本 `/responses`。

## 优化与修复

- BPS/原生混合池首选无法获取时保留 top-K 之外的合格候选，并复用有限探测预算。保留原有权重、订阅优先及显式优先级策略，不引入 fork 无条件 BPS 优先行为。无需新配置。
- 仅 HTTP 首次发送前明确发生账号路由变化时允许重新选账。取消、已写入响应、已有结果、previous_response_id、conversation、超出切换预算或后续发送错误均禁止重选。无需配置。
- Responses 入口在采用最新快照前比对路由，但模型特定校验仍保留在既有规范化后的实际发送点，避免错误拒绝映射模型。
- 流式正文/拒绝文本/推理摘要已交付后停止未知工具重生成，避免重复执行；未交付内容的既有修复仍保留。无需配置。
- 图片发送复用本地账号代理、权威状态校验和原子实际发送 RPM；原生回退同样计数，不双扣首发、不因本地拒绝增加计数。原生图片错误链保留本地 RPM/admission 类型，避免误报上游故障。
- BPS 图片只使用本账号 OAuth 身份，禁用重定向，不向 BPS 注入 Codex ticket/cookie。运输诊断记录实际图片端点并脱敏。
